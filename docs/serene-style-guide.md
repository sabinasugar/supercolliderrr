# Serene Gallery — гайд по постам

Источник: Figma `serene` (QlJCiMLigvViyjs24jBzBp), страница `posts`.
Финальные макеты — секции **Section 1**, **Section 2**, **Интервью**. Фреймы вне секций (y ≈ 9345–12445) — ранние черновики с плейсхолдерами, на них не ориентируемся.

## 1. Формат

- Карусель Instagram, **1080 × 1350** (4:5).
- Фон всех слайдов — **#F5F5F5** (тёплый светло-серый, не белый).
- Никаких плашек, рамок, теней, скруглений, градиентов. Только текст и изображения на фоне.

## 2. Цвета

| Токен | Значение | Где |
|---|---|---|
| `bg` | `#F5F5F5` | фон слайда |
| `ink` | `#1B1B1B` | заголовки, основной текст |
| `black-85` | `rgba(0,0,0,.85)` | «SERENE GALLERY» на обложке |
| `muted` | `#87857D` | рубрики, футер, надзаголовки разделов |
| `muted-dark` | `#666159` | рубрика в Section 1 (ранний вариант, лучше `#87857D`) |

Цвет в постах дают только работы художников — интерфейс монохромный.

## 4. Сетка и отступы

- Поля: **60 px** слева и справа (рабочая ширина ~960), сверху **70 px**. В Section 1 — 50 px; новые посты делаем на 60/70.
- Отступ от рубрики до текста: **56 px**.
- Отступ от имени до «год, город»: **18 px**, от него до текста: **32 px**.
- Обложка: блоки в колонке с отступом **24 px**, между двумя работами — **~30 px**.
- Футер интервью: базовая линия на y ≈ 1262.
- Всё выравнивается по центру по горизонтали, кроме текстовых блоков (слева).

## 5. Шаблоны слайдов

### A. Обложка мероприятия (`Serene - Slide1 Cover`)
1. «SERENE GALLERY» (96) + «на {ярмарка} {год}» (45 Light), по центру сверху (y = 99).
2. Две работы рядом, ~478 × 620–650, на всю ширину поля.
3. Имя художника (45) → знак-тильда «~» (вектор 37 × 12) → даты и стенд (45 Medium, 2 строки).
4. Нижняя строка (y ≈ 1244): слева адрес площадки (18), по центру логотип ярмарки (~150 px), справа логотип SERENE gallery (~154 px).

### B. Био — обложка художника
- Портрет по центру, ~534–567 × 700–756, сверху 70 px.
- Ниже: ИМЯ (Cormorant SC 70) → «1992, БЕЛГРАД» (Manrope SemiBold 32) → 3–4 строки текста (Light 36), всё по центру.

### C. Био — тематический слайд (Образование / Выставки / Переезд / О творчестве)
- Сверху слева: рубрика (Cormorant SC 32, `muted`) → текст (Light 36), 3–6 строк.
- Снизу работа в одном из двух вариантов:
  - **под обрез**: 1080 × ~720–780, прижата к нижнему краю (горизонтальные работы);
  - **«на стене»**: по центру ~570–655 × 753, снизу поле ~60–80 px (вертикальные работы).

### D. Интервью — титульный
- Портрет по центру (~567 × 756), под ним «ИНТЕРВЬЮ» (Manrope SemiBold) и ИМЯ (Cormorant SC 70).

### E. Интервью — разделитель
- Пустой слайд, по центру: «ИМЯ — ИНТЕРВЬЮ» (Manrope SemiBold 32, `muted`) + название раздела (Cormorant SC 70, `ink`, 1–2 строки).

### F. Интервью — вопрос/ответ
- Вопрос (Cormorant SC 32, 2–4 строки) → работа по центру (~280–616 px в ширину, высота ≤ 434–520) → ответ (Light 36).
- Порядок «вопрос → картинка → ответ» финальный; вариант «вопрос → ответ → картинка внизу» — альтернативный.
- Футер «ИМЯ — ИНТЕРВЬЮ» (13, `muted`) внизу слева на каждом слайде с вопросом.
- Объём ответа: до ~12 строк. Если длиннее, картинку уменьшаем или делим ответ на два слайда.

### G. Текст о проекте / экспозиции (Section 1)
- Рубрика «ХУДОЖНИК — «НАЗВАНИЕ»» сверху → абзац Light 36 → фото экспозиции под обрез внизу (или группа из 2–3 работ в разбивку сверху).

## 6. Структура карусели

| Серия | Слайды |
|---|---|
| Анонс ярмарки | A → (G: концепция стенда) → B → C… для каждого художника |
| Био художника | A (обложка с его работами) → B → C «Образование» → C «Выставки» → C «О творчестве» |
| Интервью | D → E (раздел) → F × 2–4 → E → F… |

## 7. Правила работы с изображениями

- Работы не обрезаем, если они стоят «на стене» (по центру с полями). Обрезать можно только фото экспозиции и работы под обрез.
- Скругления, обводки, тени не используем.
- Слои с изображениями называем подписью работы: `Художник, Название_ Техника_ Год_ Размер`. Это источник для подписи в тексте поста.
- Портреты художников — живые, документальные фото с естественным светом.

## 8. Тон текста

- Спокойный, кураторский, без восклицательных знаков и эмодзи на слайдах.
- Абзац на слайде — одна мысль, 3–6 строк.
- Кавычки-ёлочки «», длинное тире —, неразрывные пробелы перед тире.
